# Pagina-de-Bp_Pagina-web-Fetch-API
Asignacion de web
Es una aplicación web interactiva para explorar los perfiles y detalles de las integrantes de BLACKPINK, consumiendo información desde una API propia creada en JSONBin.io.

## ¿De qué trata?
Este proyecto nació como una práctica de manipulación del **DOM** y consumo de APIs mediante **Fetch** en JavaScript. La página permite visualizar tarjetas informativas de Jisoo, Jennie, Rosé y Lisa con datos como su apodo, rol, edad y debilidades

### Funcionalidades principales:

* **Búsqueda por texto:** Barra de búsqueda para filtrar integrantes escribiendo su nombre en minúsculas
* **Filtros rápidos:** Botones interactivos para mostrar todas las integrantes o seleccionar a una en específico
* **Datos dinámicos:** Toda la información de los perfiles se obtiene de forma asíncrona desde un repositorio JSON alojado en la nube

##  Tecnologías usadas

* **HTML5** - Estructura semántica de la página (index.html)
* **CSS3** - Diseño visual en modo oscuro con paleta de colores rosados y tarjetas responsivas (micss.css)
* **JavaScript (ES6+)** - Lógica de filtrado, manipulación dinámica del DOM y peticiones asíncronas (java.js)
* [JSONBin.io](https://jsonbin.io/) - Alojamiento y servicio de API REST en formato JSON para los datos de las integrantes

##  Estructura del proyecto

* index.html - Archivo principal de la interfaz
* micss.css - Hoja de estilos personalizados
* java.js - Script con la conexión a la API y eventos de búsqueda
* jfif - Imagenes locales de cada integrante (jisoo, jennie, rosita, lisa)
